# СВЕТ / 03

Демонстрационный сайт вымышленной московской фотостудии для портфолио веб-разработчика. Реальные услуги не оказываются.

## Статус: этап 1

Реализованы адаптивная главная, шапка с мобильной навигацией, обзор трёх пространств, информация о студии, преимущества, описание будущего бронирования и футер. Ссылки ведут к секциям главной. Каталог, страницы залов, форма бронирования, Supabase и админка ещё не реализованы. Формы сбора данных нет.

## Локальный запуск

Node.js 24 LTS и npm 11. Версии зависимостей зафиксированы в package-lock.json.

```sh
npm ci
npm run dev
```

Откройте http://localhost:3000. Для этапа 1 переменные окружения не нужны, список описан в `.env.example`. `.env.local` и секреты исключены из Git.

```sh
npm run lint
npm run typecheck
npm run build
npm start
```

`typecheck` можно запускать отдельно; первая сборка Next.js генерирует собственные типы маршрутов. `npm start` запускает результат production-сборки.

## Структура

- `src/app` — App Router, главная, метаданные и глобальные стили/токены Tailwind CSS 4.
- `src/components` — общие шапка и футер.
- `src/data/rooms.ts` — публичные данные обзорных карточек.
- `public/placeholders` — оригинальные SVG-заглушки; источники в `SOURCES.md`.

Главная и общие компоненты — серверные. Мобильная навигация использует нативный `details`, клиентский JavaScript для неё не требуется. Шрифты Onest Variable и IBM Plex Mono хранятся локально через Fontsource; запросы к Google Fonts не нужны.

Дизайн: фон #F6F7F4, текст #1B1D1B, акцент #284B42, максимальная ширина 1360 px. Основная композиция укладывается в 12/8/4-колоночную модульную сетку: половины, трети и четверти, на мобильном — последовательный поток. Отступы 48 px на desktop и 20 px на mobile; промежуточный размер — 32 px.

Будущие секреты нужно вводить в настройках платформы, не в Git.
